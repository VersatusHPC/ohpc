The Ubuntu recipe keeps the upstream optional \OmniPath{} section, but Ubuntu
24.04 does not provide the EL Omni-Path package set used by the RPM recipes.
Sites that require Omni-Path should add the vendor-supported Ubuntu packages or
a local repository before enabling this option.
