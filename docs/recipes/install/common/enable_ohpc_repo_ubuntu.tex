To begin, enable use of the \texttt{VersatusHPC} \texttt{\baseOS{}}
repository by installing the OpenHPC release package. This mirrors the upstream release-package
workflow: the release package installs the repository configuration and signing
key, then APT metadata is refreshed from the enabled repository.

% begin_ohpc_run
% ohpc_comment_header Install OpenHPC ohpc-release \ref{sec:enable_repo}
\begin{lstlisting}[language=bash,keywords={},basicstyle=\fontencoding{T1}\fontsize{7.6}{10}\ttfamily,
    literate={-}{-}1]
[sms](*\#*) export OHPC_REPO_ROOT=https://repos.versatushpc.com.br/openhpc/versatushpc-4
[sms](*\#*) export OHPC_UBUNTU_REPO=${OHPC_REPO_ROOT}/Ubuntu_24.04
[sms](*\#*) export OHPC_RELEASE_DEB=ohpc-release_4.0-1ohpc4~noble_all.deb
[sms](*\#*) apt -y install ca-certificates curl
[sms](*\#*) curl -fsSLO ${OHPC_UBUNTU_REPO}/all/${OHPC_RELEASE_DEB}
[sms](*\#*) apt -y install ./${OHPC_RELEASE_DEB}
[sms](*\#*) rm -f ${OHPC_RELEASE_DEB}
[sms](*\#*) apt update
\end{lstlisting}
% end_ohpc_run

\begin{tcolorbox}[]
\small Many sites may find it useful or necessary to maintain a local copy of the
\OHPC{} repositories. To facilitate this need, standalone tar archives are
provided containing the signed APT repository, binary packages, and metadata for
local mirrors. The tar files also contain a simple bash script to configure the
package manager to use the local repository after download. To use, simply
unpack the tarball where you would like to host the local repository and execute
the \texttt{make\_repo.sh} script. Tar files for this release can be found at
\href{https://repos.versatushpc.com.br/openhpc/versatushpc-4/Ubuntu_24.04/dist/4.0}
{\color{blue}{https://repos.versatushpc.com.br/openhpc/versatushpc-4/Ubuntu_24.04/dist/4.0}}
\end{tcolorbox}
\end{center}
