To add the optional NVIDIA GPU driver to the compute nodes, an
additional external \pkgmgr{} repository provided by NVIDIA
must be configured. Once the repository is configured the
GPU driver and the corresponding toolkit needs to be installed:

% begin_ohpc_run
% ohpc_validation_newline
% ohpc_command if [[ ${enable_nvidia_gpu_driver} -eq 1 ]];then
% ohpc_indent 5
\begin{lstlisting}[language=bash,literate={-}{-}1,keywords={},upquote=true]
# Add NVIDIA GPU driver repository to the SMS
[sms](*\#*) (*\addrepo*) (*\cudarepo*)
# Add NVIDIA GPU driver repository to the compute nodes
[sms](*\#*) (*\chrootaddrepo*) (*\cudarepo*)
# Install the GPU driver on the compute nodes
[sms](*\#*) nodeshell compute dnf -y module install nvidia-driver:latest-dkms
# Install the toolkit on the compute nodes
[sms](*\#*) (*\chrootinstall*) cuda-toolkit
# Install the toolkit on the SMS
[sms](*\#*) (*\install*) cuda-toolkit nvidia-driver-cuda
# Enable DKMS service to automatically rebuild driver
[sms](*\#*) nodeshell compute systemctl enable dkms
\end{lstlisting}
% ohpc_indent 0
% ohpc_command fi
% \end_ohpc_run
