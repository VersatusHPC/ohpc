## Scope

The 4.1 update promotion scope is the release tree checked by
`scripts/promote-update-release.sh`:

- `Ubuntu_24.04` `amd64`, `all`, `ppc64el`, source, and metadata.
- `EL_10` `ppc64le`, `noarch`, source, and metadata.
- `openEuler_24.03` `ppc64le`, `noarch`, source, and metadata.

The product runtime matrix is GNU15 and oneAPI crossed with OpenMPI, MPICH,
MVAPICH2, and Intel MPI where those packages apply. POWER does not publish
oneAPI or Intel MPI packages, so those rows are `N/A`, not skipped.

## Notes And Caveats

- The compiler/MPI runtime matrix is complete for the 4.1 update promotion
  scope.
- The stronger Ubuntu full `/opt/ohpc` dependency audit passed after rebuilding
  and publishing the repaired MFEM, MUMPS, R, and amd64 Trilinos update
  packages.
- The GitHub Actions public-repo workflows for commit
  `ae791c677eb350f0934da5007731edb99c5e6f50` are not the final release proof:
  GitHub-hosted runners previously hit HTTP `403` while fetching
  `versatushpc.gpg`, and the POWER job predated the repaired full audit. The
  release evidence above is from the native validation hosts against the public
  repository.
- openEuler MVAPICH2 emitted UCX locked-memory warnings in the container. The
  smoke programs completed, the selected linkage audit passed, and the script
  exited successfully.
