  - `POWER Public Repository Validation` run `25115130946` passed metadata

  smoke programs completed, the selected linkage audit passed, and the script
  exited successfully.

## Full `/opt/ohpc` Audit Finding

The Ubuntu ppc64el GNU15 MPI rows passed the release matrix criteria, but the
extra full-library audit found higher-level library ABI problems:

- `mfem-gnu15-mpich-ohpc` and `mfem-gnu15-mvapich2-ohpc` install
  `libmfem.so.4.9` linked against `libpetsc.so.3.24`, while the public
  repository now installs PETSc `3.25.0` and provides `libpetsc.so.3.25`.
- `mumps-gnu15-{mpich,mvapich2,openmpi5}-ohpc` installs libraries linked
  against `libscalapack.so.2`, while the public repository installs ScaLAPACK
  `2.2.3` and provides `libscalapack.so.2.2`.

If the GA gate is the compiler/MPI product matrix defined above, the matrix is
complete. If the GA gate includes full dependency closure for installed
higher-level libraries, rebuild or repair the affected Ubuntu ppc64el MFEM and
MUMPS packages before publishing.
